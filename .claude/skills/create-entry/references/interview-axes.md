# インタビューの問いの軸

`/grilling` でテーマを深掘りする際、以下の6軸に沿って一問一答で進める。各問いには推奨回答を添え、ユーザーの回答を待ってから次の問いに進むこと。

- **核心**: この記事で一番言いたいことは何か（一文で言うと？）
- **出発点**: 個人的な体験・もやもやから始まるのか、外部の情報・構造分析から始まるのか
- **問題意識**: なぜ今これを書くのか、何が引っかかっているのか
- **着地点**: 記事はどこに着地するのか、読者に何を持ち帰ってほしいのか
- **具体**: 主張を裏付ける具体的なエピソード・データ・観察は何か
- **反例・限界**: この主張が崩れるケース、反論されそうな点はどこか

## モードの確定

「出発点」の問いへの回答は、`contents-guideline.md` の「記事のモード」表に照らしてそのままエッセイ型/分析型の判定材料になる。この問いのやり取りの中で、AIは回答を踏まえたモードの判断（エッセイ型か分析型か）を提示し、ユーザーに確認する。ここでモードが確定し、以降のステップ（構造プラン作成）で独立したモード提案は行わない。

## 収束の目安

6軸すべてについて、ユーザーとAIの間で認識の齟齬がなくなった時点でインタビューを終了し、構造プラン作成（ステップ3）に進む。
