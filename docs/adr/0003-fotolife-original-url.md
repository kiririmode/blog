# エントリにはフォトライフの元の大きさの URL を書く

Status: superseded by ADR-0004

フォトライフのAPIが返す`hatena:imageurl`は、横幅450pxの縮小版URLを指す。これをそのまま本文に書くと、図が縮小されたまま公開される。そこで、スクリプトは拡張子の前に`_original`を付けた元の大きさのURLを本文に書き、縮小版URLはコミット前とCIの検査で弾く。2026-11-23に、実際の画像で縮小版が450×270、元の大きさが2000×1200であることを確かめた。

## Consequences

検査は変更したファイルだけを見る。2026-11-23の時点で、公開済みエントリに縮小版URLが5件残っているが、書き換えない。
